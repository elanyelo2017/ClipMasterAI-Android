ClipMaster AI – Android

Aplicación Android para crear clips automáticamente a partir de videos de YouTube.

Objetivo

- Detección automática de momentos virales.
- Creación de clips verticales 9:16.
- Subtítulos automáticos con estilo viral.
- Generación de títulos mediante IA.
- Exportación para TikTok, YouTube Shorts, Facebook Reels e Instagram Reels.

Configuración

- Dispositivo objetivo: OUKITEL G3.
- Plataforma: Android.
- Procesamiento: local, sin nube.
- Presupuesto: gratuito, sin suscripción.
- Publicación: revisión manual antes de publicar.

Estado del proyecto

Desarrollo en progreso.

Las funciones indicadas son objetivos del proyecto y no se consideran implementadas hasta comprobarlas.
